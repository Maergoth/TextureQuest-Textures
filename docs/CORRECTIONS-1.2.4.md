# Texture corrections 1.2.4

Three corrected color textures and one new companion surface map:

- Shared Fae/Arasai male and female bodies, rebuilt from saved original UV sheets with native AI.
- Qeynos guild-hall stone trim and its companion map, corrected together.

Original formats, mip counts, tails and all protected alpha blocks remain intact. Other released textures and categories are preserved. These are explicit manual corrections, separate from the ongoing LOCAL Qwen batch. They do not establish full guild-hall map coverage or normal-vector semantics.

The current installer still uses PAK downloads. This repository supplies the cumulative individual-DDS source for future integration.
